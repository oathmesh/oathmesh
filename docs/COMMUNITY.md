# OathMesh Community

Welcome — we're building OathMesh with a practical, security-first, developer-friendly mindset.

## How to participate

- Ask questions and get support: [SUPPORT.md](../SUPPORT.md)
- Report bugs or request features: [GitHub Issues](https://github.com/oathmesh/oathmesh/issues)
- Contribute code or docs: [CONTRIBUTING.md](../CONTRIBUTING.md)
- Review expected behavior and standards: [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)
- Report vulnerabilities responsibly: [SECURITY.md](../SECURITY.md)

## Good first contribution paths

- Improve setup clarity in [Getting Started](GETTING_STARTED.md)
- Add framework notes to [Quickstarts](quickstarts/)
- Expand troubleshooting in [FAQ](FAQ.md)
- Improve definitions in [Glossary](GLOSSARY.md)
- Strengthen operations guidance in [operations/](operations/)

## Community principles

- Be respectful and direct
- Focus on reproducible issues and actionable fixes
- Default to clear writing and secure defaults
- Favor small, reviewable pull requests

Thanks for helping make machine-to-machine security easier to build and run.
